# Oracle — fichiers de mise à jour

Dépôt public des releases Windows pour Oracle.

Le code source est dans le dépôt privé `oracle-desktop`. Ce dépôt ne contient que les installeurs publiés.

Chaque version `vX.Y.Z` doit contenir l'installeur, `latest.yml`, et le fichier blockmap.

L'application installée interroge `JokayrMP4/oracle-desktop-releases`.
